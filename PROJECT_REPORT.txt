===============================================================================
                    ARCHITECTURE & WORKFLOW SUMMARY
===============================================================================

SCRAPING WORKFLOW:
  1. User runs: python main.py update (or specific comic update)
  2. scraper.py fetches data from komiku.org
  3. BeautifulSoup parses HTML, extracts: title, chapters, images
  4. Cloudinary uploads images to CDN
  5. JSON saved to data/[comic-id].json
  6. index.json updated with new comic metadata
  7. push.py deploys changes to GitHub → Netlify

WEB READER WORKFLOW:
  1. User visits index.html (greedycomichub.netlify.app)
  2. JavaScript fetches data/index.json and data/updates.json
  3. Comics displayed in grid layout (styled with CSS)
  4. User clicks comic → comic.html with query param ?comic=[id]
  5. Dynamic content loaded from data/[id].json
  6. User selects chapter → chapter.html with ?comic=[id]&chapter=[num]
  7. Chapter images displayed via image gallery
